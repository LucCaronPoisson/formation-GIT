
# Blog Normandie Web School

Ceci est le site du blog de l'école Normandie Web School.
Il doit être accessibles à tous les étudiants et formateurs de la normandie web school mais aussi à tous.
les personnes de l'école doivent être les seuls à pouvoir poster sur le blog.
on doit donc y faire : 
- le visionnage des articles (page accueil)
- la création de ceci par tous les étudiants.
- page des articles possibles
- création de comptes
    - nom
    - prenom
    - adresse mail
    - mot de passe
    - affilié ou non à l'école 
- connection au compte
    - addresse mail
    - mot de passe

Il sera fait avec la version du react 19.3.1
Il utilisera une base de donnée MySQL en version 9.7.4 avec liaison avec le site grâce à node.js en version 26.x
